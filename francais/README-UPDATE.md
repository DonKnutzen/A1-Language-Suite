# GitHub Pages: dieses Update einspielen

1. `francais-update-v3.zip` entpacken.
2. Dein GitHub-Repository öffnen.
3. In den Ordner **francais** wechseln.
4. **Add file → Upload files** wählen.
5. `app.js`, `data.js` und `service-worker.js` hineinziehen.
6. Unten **Commit changes** klicken.
7. 1–3 Minuten warten und deine bestehende GitHub-Pages-Adresse neu laden.

Es muss **nichts** unter Settings → Pages neu eingerichtet werden. Die bestehende GitHub-Pages-Konfiguration bleibt erhalten.

Wenn auf dem iPhone noch die alte App erscheint: Safari komplett schließen und neu öffnen. Falls nötig, die Website-Daten deiner `github.io`-Seite löschen. Der Cache-Name wurde für dieses Update bereits geändert.
