# Deutsch A1 – Update V4 auf GitHub Pages

1. Öffne dein bestehendes GitHub-Repository.
2. Öffne den Ordner `deutsch`.
3. Klicke **Add file → Upload files**.
4. Lade `app.js` und `service-worker.js` aus diesem Update hoch. GitHub ersetzt die alten Dateien.
5. Klicke **Commit changes**.
6. Warte kurz auf GitHub Pages und lade die bestehende Seite neu.

`Settings → Pages` muss nicht erneut eingerichtet werden.

Falls ein iPhone noch die alte Version zeigt: Safari schließen und neu öffnen. Falls nötig die Website-Daten der GitHub-Pages-Domain löschen.
